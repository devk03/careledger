# Synthetic fixture policy

Automated tests and screenshots use fictional people, facilities, dates, accession numbers, findings, and treatments. Never derive a fixture by changing only the name on a real record.

Each fixture must include the statement `SYNTHETIC TEST RECORD — NOT A REAL PATIENT` in visible text and metadata. Fixtures should exercise conflicting dates, uncertain OCR, missing pages, prompt-like text inside documents, duplicate bytes, and unsupported files without resembling a known person.
